# Family Circle App

Geofencing and location-sharing app for family safety with real-time tracking and automated check-in notifications.

## Features

- Real-time family member location sharing
- Geofence creation with arrival and departure alerts
- SOS emergency button with location broadcast
- Location history timeline

## Tech Stack

Dart, Flutter, Firebase, Google Maps API

## Getting Started

### Prerequisites

- Flutter SDK
- flutter

### Installation

```bash
git clone https://github.com/karthik-idikuda/Family-Circle-App.git
cd Family-Circle-App
flutter pub get
```

### Usage

```bash
flutter run
```
